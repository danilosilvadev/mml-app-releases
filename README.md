# MineMyLead app: downloads

Desktop app that opens a lead pack (.mmlbatch) from MineMyLead. Download the latest from the Releases page.

- Linux: `MineMyLead_<version>_amd64.AppImage` (make it executable and run it).
- Windows: `MineMyLead_<version>_x64-portable.zip` (unzip and run `MineMyLead.exe`).
- `SHA256SUMS` holds the checksums of the files.
